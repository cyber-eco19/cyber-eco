## My Project

### RJ Juice — Bangladesh from the Sky

RJ Juice is a 3D sightseeing flight game where players fly a private jet across the 64 districts of Bangladesh.

The project includes:

- First-person cockpit flight
- External aircraft view
- Runway takeoff
- Bangladesh district selection
- Real district boundaries
- OpenStreetMap roads and waterways
- SRTM elevation terrain
- Sylhet and Chattogram sightseeing scenes

## Controls

- W — Move forward
- S — Slow down or reverse
- Arrow Up / Q — Climb
- Arrow Down / E — Dive
- A / D — Bank
- Shift — Boost
- V — External aircraft view
- Esc — Pause
